# Modeling with First-Order Equations
Back to [[academic/math-212/Index|Index]] · Chapter 2.3

## Three-step process
1. **Construct the model.** Choose variables and write the rate of change as rate in minus rate out.
2. **Analyze the model.** Solve it exactly or study it qualitatively.
3. **Compare with experiment.** Check the result against observations.

## Common problem types
- **Mixing and compartment models:** $\dfrac{dQ}{dt} = (\text{rate in}) - (\text{rate out})$
- **Finance:** $\dfrac{dS}{dt} = rS + k$ (continuous compounding with deposits)
- **Motion with resistance:** $m\dfrac{dv}{dt} = mg - \gamma v$ (linear drag), or with quadratic drag $\gamma v^2$
- **Newton's law of cooling:** $\dfrac{du}{dt} = -k(u - T)$
- **Torricelli's law:** $\dfrac{dV}{dt} = -\alpha a\sqrt{2gh}$
- **Escape velocity:** $v\dfrac{dv}{dx} = -\dfrac{gR^2}{(R + x)^2}$
